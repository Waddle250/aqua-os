<h1>Aqua OS</h1>
AquaOS is a collaborative project between Waddle250(the owner), and EAQ150. This is a hobby project, and we have a couple of goals and rules in mind when it comes to actually making the OS.
<h4>Goals/Rules</h4>
<ul>
  <li>We must make everything from scratch, meaning no using Limine or GRUB (The only exception is incorporating OpenGL or Vulkan, but that's for compatability reasons)</li><br>
  <li>ANYONE CAN HELP! If you have any ideas on how to make it better, you can put it under Issues, and of you have a fix, please do not be afraid to help.</li>
</ul>
